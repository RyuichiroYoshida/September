# 目標
触手状のオブジェクトがコリジョンに衝突した際に、自然に見える方法で衝突を解決するための衝突ソルバークラスを作成してください

# 概要
IKを使用した、手続き的な触手アニメーションに対して、コリジョンにめり込まない処理を追加するための機能です。
このアニメーションは、クラーケンのようか巨大な生物が、船の甲板に対して触手を振り下ろすというものです。
衝突を解決する際には、甲板から若干浮いたり、めり込んだりしないようにする必要があります。
また、振り下ろした後は甲板に一定時間とどまり、しばらくしてから海中に腕を戻すアニメーションをする必要があります。この一連のアニメーションは連続しているものと想定して良いです。
衝突対象であるコリジョンは、簡易的にボックスコライダーを使用して作成しています。ボックスコライダーは場所によって高さがことなるようになっており、また、複数のボックスコライダーにたいして横断するように衝突する可能性があります。
このクラスは、IKFollowerクラスから利用されることを想定しており、位置と回転を持つ構造体であるIKFollower.Pointを元に動作するようにしてください。

- 拘束条件
  - 非侵入拘束：コライダー内に侵入してはいけません。
  - 回転拘束：触手のボーンの急激な回転はメッシュを破綻させてしまうため禁止されます。n°以上の回転は不可能であるようにする必要があります。
  - 距離拘束：触手のボーン間の距離は一定に保たれる必要があります。これもメッシュが破綻しないようにするために必須です。
